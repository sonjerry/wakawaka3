```bash
cd ~/repos/wakawaka3/esc-lab-rcxaz30a-v2
chmod +x run_esc_lab.sh
bash run_esc_lab.sh
```

브라우저: `http://<PI_IP>:8770`

- 40 / 50 / 60 / 100 / 200 / 333 Hz
